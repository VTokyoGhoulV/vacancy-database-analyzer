# Vacancy Database Analyzer

Консольная программа для анализа вакансий в PostgreSQL. Загружает локальный JSON и позволяет получить сводку по компаниям, сравнить зарплаты и найти вакансии по названию.

**Стек:** Python 3.14, PostgreSQL, psycopg2, python-dotenv, Poetry.

## Возможности

- Импорт вакансий и сведений о работодателях в связанные таблицы.
- Обновление существующих записей при повторной загрузке.
- Подсчёт вакансий у каждой компании.
- Вывод вакансий с работодателем, зарплатой, местоположением и требованиями.
- Расчёт средней зарплаты и поиск предложений выше неё.
- Поиск по названию без учёта регистра.

В `data/hh_vacancies.json` есть пример из 25 вакансий пяти работодателей. Программа читает этот файл, запросов к hh.ru не делает.

## Запуск

Нужны Python 3.14, Poetry и PostgreSQL. Команды ниже — для PowerShell.

```powershell
git clone https://github.com/VTokyoGhoulV/vacancy-database-analyzer.git
cd vacancy-database-analyzer
poetry install --no-root
Copy-Item .env_example .env
```

В `.env` укажите пароль PostgreSQL:

```dotenv
DB_PASSWORD=your_postgres_password
```

Адрес `localhost`, база `vacancies` и пользователь `postgres` заданы в `main.py`. При стандартных настройках используется порт 5432.

Перед первым запуском создайте отдельную базу:

```powershell
psql -U postgres -h localhost -c "CREATE DATABASE vacancies;"
```

Если `psql` недоступен из терминала, выполните `CREATE DATABASE vacancies;` в pgAdmin, подключившись к базе `postgres`.

```powershell
poetry run python main.py
```

Программа создаст таблицы, загрузит данные и откроет меню. Пункты `1`–`5` выполняют запросы, `0` завершает работу. При повторном запуске записи с теми же идентификаторами обновляются.

## Устройство

SQL-запросы находятся в `src/classes.py`, создание таблиц и импорт — в `src/db_creator.py`.
Таблица `employers` хранит данные работодателя для каждой вакансии и связана с `vacancies` через `vacancy_id`.

Автоматических тестов пока нет.

## Ограничения

- Базу нужно создать вручную: функция её создания не обрабатывает обычную ошибку подключения к отсутствующей базе.
- Импорт ожидает заполненные числовые поля, в том числе обе границы зарплаты. Пустые значения или отсутствующие ключи могут прервать загрузку; уже добавленные записи останутся в базе.
- Средняя зарплата считается по серединам диапазонов с округлением вниз. Пересчёта валют нет, а вывод всегда подписан в рублях — используйте выборку в рублях.
- Данные обновляются только при загрузке JSON.
